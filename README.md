# Sogon Studio

모바일 앱을 직접 만들고 운영하는 1인 개발 스튜디오입니다. 이 저장소는 자사 앱 소개 웹사이트입니다.

사이트: https://sogonstudio.com/
회사 소개: https://sogonstudio.com/about.html

## 앱

**소곤사주**: 내 사주를 근거로 지금의 고민에 답하는 상담 앱입니다. 생년월일시로 사주를 계산하고, 그 계산에 근거해 질문에 답합니다. 답변에는 사주표, 오행 균형, 십성, 대운 중 무엇을 보고 그렇게 말했는지 근거가 함께 붙습니다. 회원가입이 없고 개인 정보는 사용자 기기에만 저장됩니다.

https://play.google.com/store/apps/details?id=com.sogonsaju.app

**소곤작명**: 사주를 근거로 이름을 짓는 앱. 개발 중입니다.

**소곤신점**: 오방기를 뽑아 무녀에게 물어보는 신점 앱. 개발 중입니다.

**소곤해몽**: 근거가 보이는 꿈풀이 앱. 개발 중입니다.
